# Add real project photos here

1. Copy optimized `.webp` or `.jpg` files into this folder (or `placeholders/` until you replace them).
2. Update entries in [`src/data/gallery.ts`](../../src/data/gallery.ts):
   - `src` path under `/images/gallery/...`
   - `width` and `height` matching the file
   - Descriptive `alt` text and `caption`
   - `category` for filters
3. Rebuild with `npm run build`.

Use descriptive filenames (for example `panel-upgrade-main-st-2025.webp`).
